# 个人信息台

个人工作信息收集、沉淀与长期职业记录平台（Apple 玻璃风格 · 单文件站点）。

- 站点入口：`index.html`（双击即可本地打开，或访问 GitHub Pages 地址）
- 配套文档：`个人信息台-PRD-v0.5.md`（产品需求）、`个人信息台-UI设计方案-白色版.md`（UI 设计规范）
- 站点为纯静态单文件，无外部依赖、无构建步骤。

## 更新站点

1. 修改 `index.html`
2. `git add index.html && git commit -m "更新" && git push origin main`
3. GitHub Actions 自动构建 Pages，约 1 分钟生效
